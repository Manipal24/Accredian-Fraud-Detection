## Key Project Questions Answered

1. **Data Cleaning**: Missing values (identified and imputed), outliers (removed using IQR), multicollinearity (VIF analysis)
2. **Model Description**: Random Forest classifier with feature importance analysis
3. **Feature Selection**: Correlation-based and recursive feature elimination methods
4. **Model Performance**: ROC-AUC curve, confusion matrix, precision, recall, F1-score
5. **Key Fraud Predictors**: Top features identified through SHAP values and feature importance
6. **Domain Validity**: Explained why identified factors make business sense for fraud detection
7. **Prevention Infrastructure**: Recommended ML pipeline deployment and real-time monitoring
8. **Success Measurement**: KPIs for detecting fraud rate, false positive reduction, and cost savings
